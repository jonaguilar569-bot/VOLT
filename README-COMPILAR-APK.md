# Compilar VOLT sin Android Studio

1. Sube este proyecto a un repositorio de GitHub.
2. Abre la pestaña **Actions**.
3. Selecciona **Build VOLT APK**.
4. Presiona **Run workflow**.
5. Espera a que termine correctamente.
6. Entra al resultado de la ejecución.
7. En la sección **Artifacts**, descarga **VOLT-debug-apk**.
8. Descomprime el archivo descargado y encontrarás `app-debug.apk`.
